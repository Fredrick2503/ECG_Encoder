description: Continue development from the current project state.
---

When the user invokes `/continue-project`, orchestrate the project using the
available agents and skills.

Execution Sequence

1. Project Manager
   - Load the current project state.
   - Review roadmap.
   - Select the highest-priority task.

2. Environment Manager
   - Validate development environment.
   - Validate dependencies.
   - Update tooling if required.

3. System Architect
   - Review architecture.
   - Validate interfaces.
   - Determine architectural impact.

4. Appropriate Engineering Agent
   - Implement the selected task.
   - Follow engineering standards.

5. Testing Agent
   - Execute unit and integration tests.

6. Research Scientist
   - Validate implementation.
   - Verify research quality.

7. Clinical Reviewer
   - Validate medical correctness when applicable.

8. Project Memory
   - Record implementation.
   - Update roadmap.
   - Update backlog.
   - Update milestones.
   - Record technical decisions.

9. Research Workspace Manager
   - Detect implementation changes.
   - Update affected notebooks.
   - Add API examples.
   - Generate visualizations.
   - Update architecture diagrams.
   - Synchronize playground notebook.
   - Update notebook index.

10. Research Documentation
   - Link notebook updates to thesis notes.
   - Update implementation journal.

11. Project Planner
   - Recommend next task.

Stop after reporting completed work.
