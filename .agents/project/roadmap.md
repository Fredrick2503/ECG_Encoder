# Project Roadmap

## Phase 1 — Core Infrastructure

### Objectives

* Build Data Management
* Build Signal Preprocessing
* Build Representation Generation

### Deliverables

* Complete data pipeline
* Standardized ECGRecord
* Reusable preprocessing engine
* Representation generators

---

## Phase 2 — Temporal Representation Learning

### Objectives

* Implement Temporal Encoder
* Train baseline models
* Compare MAE, Contrastive Learning and Reconstruction

### Deliverables

* Temporal Encoder
* Training framework
* Baseline experiments
* Performance benchmarks

---

## Phase 3 — Morphology Representation Learning

### Objectives

* Generate ECG image representations
* Implement Morphology Encoder
* Benchmark morphology learning

### Deliverables

* Morphology representation generator
* Morphology Encoder
* Experimental comparison with Temporal Encoder

---

# Future Roadmap (Frozen)

The following phases are intentionally frozen.

Implementation will **not** begin unless the roadmap is officially extended.

* Biomarker Encoder
* Adaptive Fusion
* Unified Classification
* Explainability
* Deployment
